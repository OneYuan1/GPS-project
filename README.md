## 使用指南

### 获取APK文件
1. **最新版本**: `LocationUploader/releases/LocationUploader-Latest.apk`
2. **安装方式**: 
   ```bash
   adb install releases/LocationUploader-Latest.apk
   ```

### 启动服务器
1. **多设备服务器** (推荐):
   ```bash
   cd Tcp
   python multi_device_server.py
   ```
2. **使用批处理文件**:
   ```bash
   start_multi_device_server.bat
   ```

### 测试功能
1. **完整测试**:
   ```bash
   python complete_multi_test.py
   ```
2. **延迟分析**:
   ```bash
   python 数据包延迟分析工具.py
   ```
