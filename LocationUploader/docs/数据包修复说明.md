# LocationUploader 数据包修复说明

## 📋 修复概述

本文档详细说明了LocationUploader应用中数据包传输过程中发现的问题及其修复方案。

## 🚨 发现的问题

### 1. HTTP明文传输被阻止
**问题描述**：
- 错误信息：`"Cleartext HTTP traffic to 116.162.80.112 not permitted"`
- 原因：Android 9.0+默认禁止HTTP明文传输
- 影响：无法通过HTTP协议上传数据到云服务器

**修复方案**：
- 更新`network_security_config.xml`，添加云服务器IP到白名单
- 在`RemoteUploadTask`中增加HTTP传输支持
- 增加连接超时时间到15秒

### 2. TCP配置读取错误
**问题描述**：
- 用户配置了TCP传输方式，但应用仍尝试HTTP传输
- 原因：`RemoteUploadTask`构造函数中`uploadMethod`默认值为"http"
- 影响：即使选择了TCP，仍出现HTTP传输错误

**修复方案**：
- 修复`RemoteUploadTask.loadConfig()`方法，正确从SharedPreferences读取传输方式
- 添加详细的配置加载日志
- 确保传输方式配置正确传递

### 3. 数据缺失问题
**问题描述**：
- 网络调试助手中显示大量`00 00 00 00`数据
- 海拔高度数据有时为0
- 速度和方向数据缺失

**修复方案**：
- 在`BinaryDataPacket`中添加数据有效性检查
- 使用`location.hasAltitude()`、`location.hasSpeed()`、`location.hasBearing()`检查数据可用性
- **重要**：当数据不可用时，保持为0.0，不进行估算（这是真实状态）
- 在UI中明确显示数据状态（有效/无效）

### 4. 卫星数量超出限制
**问题描述**：
- 总卫星数79颗，超出数据结构限制40颗
- 可能导致数据包格式错误

**修复方案**：
- 在`GNSSData.setSatellites()`中限制卫星数量为40颗
- 在`BinaryDataPacket.writeSatelliteInfo()`中确保不超过40颗卫星
- 添加详细的调试日志

### 3. GNSS数据修复

**文件**：`app/src/main/java/com/example/locationuploader/GNSSData.java`

#### 限制卫星数量：
```java
public void setSatellites(List<SatelliteInfo> satellites) { 
    // 限制卫星数量不超过40颗，避免超出数据结构限制
    if (satellites.size() > 40) {
        this.satellites = satellites.subList(0, 40);
        this.numSv = 40;
    } else {
        this.satellites = satellites;
        this.numSv = satellites.size();
    }
}
```

### 7. 远程上传任务修复

**文件**：`app/src/main/java/com/example/locationuploader/RemoteUploadTask.java`

#### 修复TCP配置读取：
```java
private void loadConfig() {
    SharedPreferences prefs = context.getSharedPreferences("LocationUploader", Context.MODE_PRIVATE);
    serverUrl = prefs.getString("remote_server_url", "");
    serverPort = prefs.getInt("remote_server_port", 80);
    useSSL = prefs.getBoolean("use_ssl", false);
    
    // 修复：从SharedPreferences读取传输方式
    String savedMethod = prefs.getString("upload_method", "tcp");
    // 如果构造函数没有传入uploadMethod（使用默认值"http"），则使用SharedPreferences中保存的值
    if (uploadMethod.equals("http")) {
        uploadMethod = savedMethod;
    }
    
    Log.d(TAG, String.format("加载配置 - 传输方式: %s, 服务器: %s:%d, SSL: %s", 
        uploadMethod, serverUrl, serverPort, useSSL));
}
```

## 🚀 使用建议

### 1. 网络配置
- 确保云服务器IP已添加到网络安全配置中
- 建议使用TCP传输方式，更稳定可靠
- 如需HTTP传输，确保服务器支持明文传输

### 2. 数据质量
- 室外环境可获得更好的GPS信号
- 室内环境建议使用网络定位
- 确保设备有足够的内存和CPU资源

### 3. 监控和调试
- 查看应用日志了解数据传输状态
- 使用网络调试助手验证数据包格式
- 定期检查服务器接收数据完整性

## 📝 注意事项

1. **数据包大小**：固定304字节，符合gnss_data.h结构体定义
2. **字节序**：使用小端字节序，符合网络传输标准
3. **卫星限制**：最多40颗卫星，超出部分会被截断
4. **数据有效性**：所有字段都有有效性检查，缺失数据用0填充
5. **传输协议**：优先使用TCP，HTTP作为备选方案
