# TCP传输方式说明

## 🎯 功能概述

TCP传输方式是LocationUploader应用新增的远程数据传输方式，专门用于与云服务器进行可靠的数据传输。

## 📋 传输方式对比

| 传输方式 | 可靠性 | 速度 | 适用场景 | 端口 |
|---------|--------|------|----------|------|
| **TCP** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | 重要数据、实时传输 | 8280 |
| HTTP | ⭐⭐⭐⭐ | ⭐⭐⭐ | 一般数据传输 | 28081 |
| HTTPS | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ | 安全数据传输 | 28081 |
| UDP | ⭐⭐ | ⭐⭐⭐⭐⭐ | 实时数据流 | 自定义 |

## 🔧 TCP传输特点

### 优势
- **可靠传输**: 保证数据完整性，不丢失数据
- **面向连接**: 建立稳定的连接通道
- **适合二进制数据**: 完美支持Send_Buf_Data结构体
- **低延迟**: 适合实时数据传输
- **自动重传**: 网络异常时自动重试

### 适用场景
- 卫星导航数据上传
- 实时位置信息传输
- 重要业务数据
- 需要高可靠性的场景

## 📱 手机应用配置

### 配置步骤
1. **打开应用** → 点击"远程网络配置"
2. **传输方式**: 选择"TCP"
3. **服务器地址**: 输入云服务器公网IP
4. **端口号**: 输入8280
5. **SSL加密**: 根据需要选择
6. **保存配置**

### 配置示例
```
传输方式: TCP
服务器地址: 123.456.789.123
端口号: 8280
SSL加密: 关闭
```

## 🖥️ 服务器端配置

### Python TCP服务器
```python
# Tcp.py 配置
class LocationServer:
    def __init__(self, host='0.0.0.0', port=8280):
        self.host = host
        self.port = port
```

### 启动服务器
```bash
cd /home/user/Tcp
python3 Tcp.py
```

### 防火墙配置
```bash
# 开放TCP端口
sudo ufw allow 8280/tcp
```

## 📊 数据传输流程

### 1. 连接建立
```
手机应用 → TCP连接 → 云服务器
```

### 2. 数据发送
```
Send_Buf_Data结构体 → 二进制数据 → TCP Socket → 服务器
```

### 3. 数据处理
```
服务器接收 → 解析数据 → 存储数据库
```

## 🔍 数据格式

### 二进制格式（优先）
- 使用Send_Buf_Data结构体
- 小端字节序
- 包含完整的GNSS信息

### JSON格式（备用）
- 当二进制格式失败时使用
- 包含位置和卫星信息
- 便于调试和查看

## ⚠️ 故障排除

### 常见问题

1. **连接被拒绝**
   - 检查服务器是否运行
   - 确认端口8280已开放
   - 检查防火墙配置

2. **数据传输失败**
   - 检查网络连接
   - 确认服务器地址正确
   - 查看服务器日志

3. **数据格式错误**
   - 检查Send_Buf_Data结构
   - 确认字节序设置
   - 验证数据完整性

### 调试命令
```bash
# 检查服务器状态

# 查看详细日志
journalctl -u location-server -f

# 测试数据库连接
mysql -u location_user -p -h localhost location_data
```
