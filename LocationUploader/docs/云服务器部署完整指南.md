# 云服务器部署完整指南

## 📋 部署概览

本指南将帮助你在腾讯云服务器上部署完整的数据接收和存储系统。

### 服务器信息
- **服务器IP**: 1.15.111.168
- **操作系统**: Windows Server
- **接收端口**: 8280
- **数据库**: MySQL (端口3306)

---

## 🚀 第一步：安装MySQL数据库

### 1.1 下载MySQL
1. 访问 [MySQL官网](https://dev.mysql.com/downloads/mysql/)
2. 下载 `mysql-installer-community-8.0.xx.x.msi`
3. 选择 "Server only" 或 "Developer Default"

### 1.2 安装配置
1. 运行安装程序
2. 设置root密码（**重要：记住这个密码**）
3. 完成安装

### 1.3 验证安装
```cmd
mysql -u root -p
# 输入密码，应该能进入MySQL命令行
```

---

## 🔧 第二步：配置防火墙

### 2.1 腾讯云控制台配置
1. 登录 [腾讯云控制台](https://console.cloud.tencent.com/)
2. 进入 "云服务器 CVM" → 你的实例
3. 点击 "安全组" → "编辑规则"
4. 添加入站规则：
   - **端口8280**: 协议TCP，来源0.0.0.0/0
   - **端口3306**: 协议TCP，来源0.0.0.0/0（仅测试用）

### 2.2 Windows防火墙配置
1. 打开 "Windows Defender 防火墙"
2. 点击 "高级设置"
3. 添加入站规则：
   - 端口8280，协议TCP
   - 端口3306，协议TCP

## 🔌 第四步：启动数据接收服务

### 4.1 下载MySQL连接器
```cmd
# 在服务器上执行
curl -L -o mysql-connector-java-8.0.33.jar "https://repo1.maven.org/maven2/mysql/mysql-connector-java/8.0.33/mysql-connector-java-8.0.33.jar"
```

### 4.2 修改数据库密码
编辑 `CloudDataReceiver.java` 第18行：
```java
private static final String DB_PASSWORD = "你的MySQL密码"; // 修改这里
```

### 4.3 启动服务
```cmd
# 运行启动脚本
启动云服务器接收服务.bat
```

**预期输出：**
```
数据接收服务已启动，监听端口: 8280
数据库连接成功
数据表创建成功
等待Android App连接...
```

## 📱 第五步：配置Android App

### 5.1 打开App设置
1. 启动LocationUploader App
2. 点击 "设置" 按钮
3. 选择 "远程网络配置"

### 5.2 配置服务器信息
- **服务器地址**: `1.15.111.168`
- **端口号**: `8280`
- **传输方式**: `TCP`
- **使用SSL**: `关闭`

### 5.3 保存配置
点击 "保存配置" 按钮

## 📊 第七步：数据监控和查询

```sql
-- 导出CSV格式
SELECT 
    client_ip as '客户端IP',
    frame_id as '帧ID',
    latitude as '纬度',
    longitude as '经度',
    altitude as '高度',

    created_at as '时间'

INTO OUTFILE 'C:/temp/gnss_data.csv'

ENCLOSED BY '"' 
LINES TERMINATED BY '\n';
```

## 🔧 故障排除

### 问题1：连接被拒绝
**症状**: App显示"连接失败"
**解决**:
1. 检查防火墙是否开放8280端口
2. 确认服务是否正在运行
3. 检查IP地址是否正确

### 问题2：数据库连接失败
**症状**: 服务启动时显示"数据库连接失败"
**解决**:
1. 检查MySQL是否正在运行
2. 验证数据库密码是否正确
3. 确认数据库已创建

### 问题3：数据包解析错误
**症状**: 服务器显示"解析数据包失败"
**解决**:
1. 检查App版本是否为最新
2. 确认数据包格式是否正确
3. 查看详细错误日志

## 🔒 安全建议

### 生产环境安全配置
1. **限制数据库访问**:
   ```sql
   -- 创建专用用户
   CREATE USER 'gnss_user'@'localhost' IDENTIFIED BY 'strong_password';
   GRANT SELECT, INSERT ON gnss_data.* TO 'gnss_user'@'localhost';
   ```

2. **配置SSL连接**:
   - 生成SSL证书
   - 配置HTTPS/TLS

3. **IP白名单**:
   - 限制特定IP访问
   - 使用VPN或专线
