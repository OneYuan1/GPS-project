# 数据结构详细说明

## 📊 数据包结构概述

LocationUploader应用严格按照`gnss_data.h`中的C结构体格式生成二进制数据包，总长度为304字节。

## 🏗️ 完整数据结构

### Send_Buf_Data (304字节)
```
Send_Buf_Data {
    TCP_FrameHeader header;    // 20字节 - 帧头信息
    GNSS_Data data;           // 284字节 - GNSS数据
}
```

## 📋 TCP_FrameHeader (20字节)

### 结构体定义
```c
typedef struct {
    uint32_t TTI;           // 4字节 - 数据包标识符
    uint32_t Number;        // 4字节 - 帧序列号
    uint16_t Package_Type;  // 2字节 - 包类型
    uint16_t Package_len;   // 2字节 - 包长度
    uint32_t Check_Word;    // 4字节 - 校验字
    uint32_t node_name;     // 4字节 - 设备标识
} TCP_FrameHeader;
```

### 字段详细说明

| 字段名 | 大小 | 值 | 说明 |
|--------|------|-----|------|
| TTI | 4字节 | 0xAAAABBBB | 数据包起始标识符，固定值 |
| Number | 4字节 | 0,1,2... | 帧序列号，每次发送自增 |
| Package_Type | 2字节 | 0x00BB | 包类型标识，固定值 |
| Package_len | 2字节 | 0x0130 | 包长度，固定值304字节 |
| Check_Word | 4字节 | 0x0000BBBB | 校验字，固定值 |
| node_name | 4字节 | 0xD******* | 设备唯一标识符 |

### 示例数据解析
```
BB BB AA AA 5E 01 00 00 BB 00 30 01 BB BB 00 00 3A 4B 64 D0
```

**解析结果**：
- `BB BB AA AA` = TTI (0xAAAABBBB) ✅
- `5E 01 00 00` = Number (帧ID: 350) ❌ 应该是自增序列号
- `BB 00` = Package_Type (0x00BB) ✅
- `30 01` = Package_len (0x0130) ✅
- `BB BB 00 00` = Check_Word (0x0000BBBB) ✅
- `3A 4B 64 D0` = node_name (设备ID) ✅

## 📡 GNSS_Data (284字节)

### 结构体定义
```c
typedef struct {
    // 时间信息 (7字节)
    uint16_t year;          // 2字节 - 年份
    uint8_t month;          // 1字节 - 月份
    uint8_t day;            // 1字节 - 日期
    uint8_t hour;           // 1字节 - 小时
    uint8_t minute;         // 1字节 - 分钟
    uint8_t second;         // 1字节 - 秒
    
    // 位置信息 (24字节)
    double lon;             // 8字节 - 经度
    double lat;             // 8字节 - 纬度
    double height;          // 8字节 - 高度
    
    // 运动信息 (12字节)
    float groundSpeed;      // 4字节 - 地面速度 (m/s)
    float heading;          // 4字节 - 航向角 (度)
    float PDOP;             // 4字节 - 位置精度因子
    
    // 卫星信息 (241字节)
    uint8_t satelliteCount; // 1字节 - 卫星数量
    Satellite_Info satellites[40]; // 240字节 - 卫星信息数组
} GNSS_Data;
```

## 🛰️ Satellite_Info (6字节)

### 结构体定义
```c
typedef struct {
    uint8_t gnssId;         // 1字节 - 卫星系统ID
    uint8_t svId;           // 1字节 - 卫星ID
    uint8_t cnos;           // 1字节 - 载噪比值 (dB-Hz)
    uint8_t elev;           // 1字节 - 仰角 (度)
    uint16_t azim;          // 2字节 - 方位角 (度)
} Satellite_Info;
```

### 卫星系统ID对照表

## 🔍 数据包示例分析

### 完整数据包示例
```
BB BB AA AA 5E 01 00 00 BB 00 30 01 BB BB 00 00 3A 4B 64 D0 E9 07 08 15 0C 08 0C ...
```

### 逐字节解析

#### TCP_FrameHeader部分 (前20字节)
```
BB BB AA AA - TTI标识符
5E 01 00 00 - 帧ID (350，小端序)
BB 00       - 包类型
30 01       - 包长度
BB BB 00 00 - 校验字
3A 4B 64 D0 - 设备ID
```

#### GNSS_Data部分 (后续字节)
```
E9 07       - 年份 (2025)
08          - 月份 (8)
15          - 日期 (21)
0C          - 小时 (12)
08          - 分钟 (8)
0C          - 秒 (12)
...         - 后续为位置、运动、卫星数据
```

## ⚠️ 常见问题分析

### 问题1：帧ID不变
**现象**：帧ID始终显示为0或固定值
**原因**：
1. 静态变量重置
2. 应用重启
3. 多线程访问问题

### 问题2：卫星数据全为0
**现象**：Satellite_Info数组全部为0
**原因**：
1. GNSS信号接收失败
2. 权限不足
3. 设备不支持GNSS

### 问题3：位置数据异常
**现象**：经纬度显示异常值
**原因**：
1. 定位精度低
2. 数据转换错误
3. 坐标系问题

## 📝 数据包验证

### 完整性检查
1. **长度验证**：确保总长度为304字节
2. **标识符验证**：检查TTI是否为0xAAAABBBB
3. **校验字验证**：检查Check_Word是否为0x0000BBBB
4. **序列号验证**：确认帧ID是否自增

### 数据有效性检查
1. **时间范围**：年份、月份、日期是否合理
2. **位置范围**：经纬度是否在有效范围内
3. **卫星数据**：卫星数量是否合理
4. **信号强度**：载噪比是否在有效范围内
