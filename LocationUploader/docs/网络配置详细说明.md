# 网络配置详细说明

## 📡 网络配置类型

### 1. 本地网络配置 (内网传输)

**适用场景**：
- 手机和服务器在同一局域网内
- 例如：手机连接WiFi，服务器也在同一WiFi网络下

**配置参数**：
- **服务器IP地址**：内网IP地址
- **端口号**：服务器监听的端口

**内网IP地址格式**：
```
192.168.x.x    (最常见)
10.x.x.x       (企业网络)
172.16-31.x.x  (企业网络)
```

**获取内网IP的方法**：
1. **Windows电脑**：
   ```cmd
   ipconfig
   ```
   查看"IPv4 地址"字段

2. **Linux/Mac电脑**：
   ```bash
   ifconfig
   # 或
   ip addr
   ```

3. **路由器管理界面**：
   - 登录路由器管理页面
   - 查看"已连接设备"列表

**端口号说明**：
- 范围：1-65535
- 默认配置：12345
- 必须与服务器端配置一致
- 常用端口：
  - 12345：自定义端口
  - 8080：HTTP备用端口
  - 80：HTTP标准端口
  - 443：HTTPS标准端口

### 2. 远程网络配置 (公网传输)

**适用场景**：
- 手机和服务器不在同一网络
- 需要通过互联网传输数据
- 使用云服务器部署

**配置参数**：
- **服务器地址**：公网IP地址或域名
- **端口号**：云服务器开放的端口
- **传输方式**：TCP/HTTP/HTTPS/UDP

**公网IP地址**：
- 全球唯一标识
- 可以从外网访问
- 由云服务商分配

**获取公网IP的方法**：
1. **云服务器控制台**：
   - 登录云服务商管理控制台
   - 查看实例的公网IP

2. **服务器命令行**：
   ```bash
   curl ifconfig.me
   # 或
   curl ipinfo.io/ip
   ```

3. **域名解析**：
   - 如果有域名，直接使用域名
   - 例如：`your-server.com`

**端口号配置**：
- 必须在云服务器防火墙中开放
- 常见配置：
  - 8080：HTTP应用端口
  - 80：HTTP标准端口
  - 443：HTTPS标准端口
  - 12345：自定义端口

## 🔧 配置步骤

### 本地网络配置步骤

1. **获取服务器内网IP**：
   ```bash
   # Windows
   ipconfig
   
   # Linux/Mac
   ifconfig
   ```

2. **启动服务器**：
   ```bash
   # 进入Tcp目录
   cd Tcp
   
   # 启动服务器
   python multi_device_server.py
   ```

3. **配置Android应用**：
   - 打开应用
   - 点击"本地网络配置"
   - 输入服务器IP和端口
   - 点击"测试连接"验证

### 远程网络配置步骤

1. **云服务器设置**：
   ```bash
   # 安装Python和依赖
   sudo apt update
   sudo apt install python3 python3-pip
   
   # 上传服务器代码
   scp -r Tcp/ user@your-server:/home/user/
   
   # 启动服务器
   cd Tcp
   python3 multi_device_server.py
   ```

2. **防火墙配置**：
   ```bash
   # Ubuntu/Debian
   sudo ufw allow 12345
   sudo ufw enable
   
   # CentOS/RHEL
   sudo firewall-cmd --permanent --add-port=12345/tcp
   sudo firewall-cmd --reload
   ```

3. **配置Android应用**：
   - 打开应用
   - 点击"远程网络配置"
   - 输入公网IP和端口
   - 选择传输方式
   - 点击"测试连接"验证

## 🚨 常见问题解决

### 连接失败问题

**问题1：本地连接失败**
```
解决方案：
1. 确认手机和服务器在同一WiFi网络
2. 检查服务器IP地址是否正确
3. 确认服务器程序已启动
4. 检查防火墙设置
```

**问题2：远程连接失败**
```
解决方案：
1. 确认公网IP地址正确
2. 检查云服务器防火墙设置
3. 确认端口已开放
4. 检查服务器程序是否运行
5. 验证网络连接状态
```

**问题3：端口被占用**
```
解决方案：
1. 更换端口号
2. 检查端口占用情况：
   # Linux
   netstat -tulpn | grep :12345
   
   # Windows
   netstat -ano | findstr :12345
```

### 网络诊断命令

**测试网络连通性**：
```bash
# 测试IP连通性
ping 192.168.1.100

# 测试端口连通性
telnet 192.168.1.100 12345

# 使用nc测试
nc -zv 192.168.1.100 12345
```

**查看网络配置**：
```bash
# 查看网络接口
ifconfig

# 查看路由表
route -n

# 查看DNS配置
cat /etc/resolv.conf
```

## 🔐 安全建议

1. **使用强密码**：设置复杂的服务器访问密码
2. **限制访问IP**：在防火墙中限制允许访问的IP范围
3. **使用HTTPS**：对于敏感数据，建议使用HTTPS传输
4. **定期更新**：保持服务器系统和软件更新
5. **监控日志**：定期检查服务器访问日志

2. IP地址和端口配置
3. 防火墙设置
4. 服务器程序状态
5. 应用权限设置
