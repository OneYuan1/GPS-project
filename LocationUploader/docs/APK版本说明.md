# LocationUploader APK版本说明

## 📱 当前可用版本

### 🎯 推荐版本
- **LocationUploader-v5.4-DataLogicFixed.apk** (1.7MB) ⭐ **推荐使用**
  - **修复内容**：TCP配置读取、数据逻辑处理、位置服务优化
  - **主要改进**：正确处理数据缺失、优化GPS数据获取、明确数据状态显示
  - **适用场景**：生产环境使用，所有功能完整

### 📦 备用版本
- **LocationUploader-Final-Release.apk** (1.7MB)
  - **版本说明**：最终发布版本
  - **功能状态**：基础功能完整，部分优化功能可能缺失
  - **适用场景**：备用版本，兼容性测试

## 📥 下载地址

所有APK文件位于 `releases/` 目录下：

```
LocationUploader/
├── releases/
│   ├── LocationUploader-v5.4-DataLogicFixed.apk  ⭐ 推荐

```

## 🔧 安装说明

1. **下载APK文件**到Android设备
2. **允许安装未知来源应用**
3. **安装应用**
4. **授予必要权限**（位置、网络等）
5. **开始使用**

## 📝 注意事项

1. **版本选择**：建议使用v5.4版本，功能最完整
2. **权限要求**：需要位置权限和网络权限
3. **兼容性**：支持Android 6.0+设备
4. **网络配置**：首次使用需要配置网络参数
