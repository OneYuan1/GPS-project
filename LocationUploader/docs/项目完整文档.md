# LocationUploader 项目完整文档

## 项目概述

LocationUploader是一个Android应用程序，用于将卫星导航模块信息上传到TCP服务器。支持多设备并发连接，严格按照gnss_data.h结构体格式进行数据对接。

- **状态**: ✅ 完全可用

### 主要功能
- 📱 **多设备支持**: 支持多个Android设备同时连接
- 🛰️ **GNSS数据采集**: 实时获取GPS/GLONASS/北斗卫星数据
- 📡 **TCP数据上传**: 将数据以二进制格式上传到服务器
- 🔄 **1秒间隔**: 每秒发送一个完整的数据包
- 📊 **数据分离**: 每个设备数据独立处理和存储
- 🏗️ **结构体格式**: 严格按照gnss_data.h C结构体格式

## 数据包结构

### Send_Buf_Data (304字节)
```
TCP_FrameHeader (20字节) {
    uint32_t TTI;           // 固定值 0xAAAABBBB
    uint32_t Number;        // 序列号，每次自增
    uint16_t Package_Type;  // 包类型 0x00BB
    uint16_t Package_len;   // 包长度 0x0130
    uint32_t Check_Word;    // 校验字 0x0000BBBB
    uint32_t node_name;     // 设备ID 0xD*******
}

GNSS_Data (284字节) {
    // NAV-PVT协议数据部分 (44字节)
    uint16_t year;          // 年
    uint8_t month;          // 月
    uint8_t day;            // 日
    uint8_t hour;           // 时
    uint8_t minute;         // 分
    uint8_t second;         // 秒
    double lon;             // 经度
    double lat;             // 纬度
    double height;          // 高度
    float groundSpeed;      // 地面速度
    float heading;          // 对地航向
    float PDOP;             // 位置精度因子
    uint8_t satelliteCount; // 卫星数量
    
    // NAV-SAT协议数据部分 (240字节)
    Satellite_Info satellites[MAX_SATELLITES]; // 40个卫星信息
}

Satellite_Info (6字节) {
    uint8_t gnssId;         // 卫星系统ID
    uint8_t svId;           // 卫星ID
    uint8_t cnos;           // 载噪比值
    int8_t elev;            // 仰角
    uint16_t azim;          // 方位角
}
```

## 快速开始

### 1. 获取APK文件
```bash
# 最新版本
LocationUploader/releases/LocationUploader-Latest.apk
```

### 2. 安装到设备
```bash
# 卸载旧版本
adb uninstall com.example.locationuploader

# 安装新版本
adb install LocationUploader/releases/LocationUploader-Latest.apk
```

### 3. 启动服务器
```bash
# 启动多设备服务器 (推荐)
cd Tcp
python multi_device_server.py

# 或使用批处理文件
start_multi_device_server.bat
```

### 4. 测试功能
```bash
# 验证语法修复
python test_syntax_fix.py

# 验证超时修复
python test_timeout_fix.py

# 完整功能测试
python complete_multi_test.py
```

## 使用说明

### 首次使用
1. 打开 **LocationUploader** 应用
2. 点击 **允许** 授予位置权限
3. 输入服务器IP和端口
4. 点击 **开始持续上传**

### 服务器配置
- **默认IP**: 192.168.1.116
- **默认端口**: 12345
- **数据格式**: 二进制 (gnss_data.h格式)

### 多设备使用
- 每个设备自动生成唯一ID
- 服务器自动分离不同设备的数据
- 支持同时连接多个设备
