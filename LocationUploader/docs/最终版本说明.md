## 📱 使用说明

### 安装步骤
1. 卸载所有旧版本
2. 安装 `LocationUploader-Final-Release-v1.0.24.apk`
3. 授予位置权限
4. 配置网络设置

### 基本使用
1. **获取位置** - 点击"获取位置"按钮
2. **开始上传** - 点击"开始上传"按钮
3. **停止上传** - 点击"停止上传"按钮
4. **配置网络** - 点击"本地网络配置"或"远程网络配置"

### 网络配置
#### 本地配置
1. 点击"本地网络配置"
2. 输入内网IP地址和端口
3. 点击"保存"

#### 远程配置
1. 点击"远程网络配置"
2. 选择传输方式（TCP/HTTP/HTTPS/UDP）
3. 输入服务器地址和端口
4. 点击"保存"

#### 切换回本地
1. 点击"远程网络配置"
2. 点击"清除配置"按钮
3. 系统自动切换回本地传输
