# LocationUploader 多设备支持功能说明

## 📋 概述

LocationUploader 系统天然支持多设备并发连接和数据上传，这是通过 `gnss_data.h` 结构体中的 `node_name` 字段实现的。

## 🔧 技术实现

### 1. 设备唯一标识

每个设备都有唯一的 `node_name` 标识：

```c
typedef struct {
    uint32_t TTI;           // 0xAAAABBBB
    uint32_t Number;        // 序号，每次自增
    uint16_t Package_Type;  // 0x00BB
    uint16_t Package_len;   // 0x0130
    uint32_t Check_Word;    // 0x0000BBBB
    uint32_t node_name;     // 0xD******* (每个设备的唯一ID)
} TCP_FrameHeader;
```

### 2. 设备ID生成策略

Android应用使用以下策略生成唯一设备ID：

1. **IMEI优先**：使用手机IMEI的后7位数字
2. **Device ID备用**：使用设备ID的后7位数字
3. **设备特征哈希**：基于制造商、型号、序列号等信息生成哈希值

### 3. 多设备管理器

新增 `MultiDeviceManager` 类负责：

- 设备唯一标识的生成和管理
- 设备信息的持久化存储
- 设备信息的统一访问接口

## 📊 多设备支持特性

### ✅ 已实现功能

1. **设备唯一标识**
   - 每个设备有唯一的 `node_name` (0xD*******)
   - 设备ID持久化存储，重启后保持不变

2. **数据包序号管理**
   - 每个设备独立维护序号
   - 序号自动递增，确保数据包顺序

3. **服务器并发处理**
   - 支持多客户端同时连接
   - 每个连接独立线程处理
   - 设备数据分离存储

4. **设备识别和显示**
   - 服务器能识别不同设备
   - 显示设备名称和ID
   - 数据包来源清晰标识

### 🚀 增强功能

1. **设备信息管理**
   ```java
   MultiDeviceManager deviceManager = MultiDeviceManager.getInstance(context);
   int nodeName = deviceManager.getNodeName();
   String deviceName = deviceManager.getDeviceName();
   ```

2. **设备信息持久化**
   - 使用 SharedPreferences 存储设备信息
   - 应用重启后设备ID保持不变

3. **设备状态监控**
   - 服务器监控在线设备数量
   - 设备连接/断开状态跟踪
   - 数据包统计信息

## 🔍 技术细节

### 1. 设备ID格式
```
设备ID: 7位数字 (0000001-9999999)
NodeName: 0xD0000000 | 设备ID
设备名称: Android_Device_XXXXXXX
```

### 2. 数据包结构
```
Send_Buf_Data (304字节)
├─ TCP_FrameHeader (20字节)
│   └─ node_name: 设备唯一标识
└─ GNSS_Data (284字节)
    ├─ NAV-PVT协议数据
    └─ Satellite_Info数组
```

### 3. 服务器处理流程
1. 接收客户端连接
2. 解析数据包中的 `node_name`
3. 注册/更新设备信息
4. 存储设备数据
5. 显示设备信息

## 📝 总结

LocationUploader 的多设备支持功能是系统设计的核心特性之一，通过 `node_name` 字段实现了：

- **设备唯一性**：每个设备有唯一标识
- **数据分离**：不同设备的数据独立处理
