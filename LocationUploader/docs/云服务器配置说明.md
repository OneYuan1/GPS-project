# 云服务器配置说明

## 🎯 配置目标

将LocationUploader应用连接到云服务器，实现远程数据上传到云数据库。

## 📋 系统架构

```
手机应用 (LocationUploader) 
    ↓ (HTTP/HTTPS/UDP/TCP)
云服务器 (您的服务器)
    ↓ (JDBC/MySQL)
云数据库 (MySQL)
```

## 🔧 配置步骤

### 1. 云服务器端配置

#### 服务器配置 (application-local.yml)
```yaml
# 端口配置
server-port: 28081  # HTTP服务器端口

# 数据库连接信息
db-driver: com.mysql.cj.jdbc.Driver
db-url: jdbc:mysql://127.0.0.1:3306/test?serverTimezone=Asia/Shanghai&rewriteBatchedStatements=true&allowMultiQueries=true
db-username: hb
db-password: '12345678'

# Netty TCP服务器配置
netty:
  tcp-port: 8280  # TCP服务器端口
```

#### 重要说明
- **127.0.0.1**: 这是云服务器本地的数据库地址
- **8280端口**: TCP服务器端口，用于接收手机应用数据
- **28081端口**: HTTP服务器端口，用于Web访问

### 2. 手机应用端配置

#### 方案一：使用TCP传输（推荐）

1. **打开应用** → 点击"远程网络配置"
2. **传输方式**: 选择"TCP"（新增选项）
3. **服务器地址**: 输入云服务器的公网IP地址
4. **端口号**: 输入8280
5. **SSL加密**: 根据需要选择
6. **保存配置**

**注意**: TCP传输方式已添加到应用中，现在支持TCP、HTTP、HTTPS、UDP四种传输方式

#### 方案二：使用HTTP/HTTPS传输

1. **传输方式**: 选择"HTTP"或"HTTPS"
2. **服务器地址**: 输入云服务器的公网IP地址
3. **端口号**: 输入28081
4. **SSL加密**: HTTPS时选择启用
5. **保存配置**

## 🌐 传输方式详解

### TCP传输 (推荐)
- **端口**: 8280
- **特点**: 可靠连接，适合二进制数据
- **优势**: 延迟低，适合实时数据传输
- **适用**: Send_Buf_Data结构体数据

### HTTP传输
- **端口**: 28081
- **特点**: 基于HTTP协议
- **优势**: 简单易用，支持Web访问
- **适用**: 一般数据传输

### HTTPS传输
- **端口**: 28081 (SSL)
- **特点**: HTTP + SSL加密
- **优势**: 数据加密，安全性高
- **适用**: 敏感数据传输

### UDP传输
- **端口**: 自定义
- **特点**: 无连接，速度快
- **优势**: 实时性好，延迟最低
- **适用**: 实时数据流

## 🔐 SSL加密说明

### 什么是SSL
- **SSL (Secure Sockets Layer)**: 安全套接字层
- **作用**: 加密数据传输，防止窃听
- **原理**: 在传输层和应用层之间添加加密层

### 启用SSL
1. **服务器端**: 配置SSL证书
2. **客户端**: 选择"使用SSL加密"
3. **连接**: 自动使用HTTPS协议

### SSL证书获取
- **自签名证书**: 开发测试用
- **CA证书**: 生产环境用
- **Let's Encrypt**: 免费SSL证书

## 🖥️ 云服务器配置详解

### 数据库配置
```yaml
# 当前配置 (云服务器本地)
db-url: jdbc:mysql://127.0.0.1:3306/test

# 如果数据库在另一台服务器
db-url: jdbc:mysql://数据库服务器IP:3306/test
```

### 网络配置
```yaml
# HTTP服务器
server-port: 28081

# TCP服务器
netty:
  tcp-port: 8280
```

### 防火墙配置
需要在云服务器防火墙中开放以下端口：
- **28081**: HTTP服务器端口
- **8280**: TCP服务器端口
- **3306**: MySQL数据库端口（如果数据库在外部）

## 🔍 配置验证

2. 查看连接结果
3. 确认服务器可访问

1. 点击"获取位置"
2. 点击"开始上传"
3. 查看服务器日志确认数据接收

### 3. 数据库验证
1. 连接云服务器数据库
2. 查询数据表确认数据插入

## ⚠️ 重要提醒

### 安全配置
- **防火墙**: 只开放必要端口
- **SSL证书**: 生产环境使用CA证书
- **数据库密码**: 使用强密码
- **访问控制**: 限制数据库访问IP

### 性能优化
- **连接池**: 配置数据库连接池
- **缓存**: 使用Redis缓存
- **负载均衡**: 多服务器部署
- **监控**: 监控服务器性能

### 故障排除
1. **连接失败**: 检查防火墙和端口
2. **数据丢失**: 检查网络稳定性
3. **性能问题**: 优化服务器配置
4. **安全问题**: 启用SSL加密

## 📞 技术支持

### 常见问题
1. **无法连接云服务器**: 检查公网IP和防火墙
2. **数据上传失败**: 检查服务器状态和端口
3. **SSL连接失败**: 检查证书配置
4. **数据库连接失败**: 检查数据库配置

### 调试方法
```bash
# 检查服务器端口
netstat -tlnp | grep 8280
netstat -tlnp | grep 28081

# 检查防火墙
iptables -L | grep 8280
iptables -L | grep 28081

# 查看服务器日志
tail -f server.log
```
