# LocationUploader TCP服务器

## 概述

本项目提供多个TCP服务器实现，用于接收和处理Android设备发送的GNSS数据。支持多设备并发连接、数据解析、延迟分析和实时监控。

## 服务器选择

### 1. 多设备服务器 (推荐)
**文件**: `multi_device_server.py`
- ✅ **多设备支持**: 支持多个Android设备同时连接
- ✅ **数据分离**: 每个设备的数据独立存储和管理
- ✅ **实时监控**: 设备状态实时监控和统计
- ✅ **完整解析**: 支持完整的GNSS数据结构解析
- ✅ **Satellite_Info**: 显示详细的卫星信息

**启动方式**:
```bash
python multi_device_server.py
# 或使用批处理文件
start_multi_device_server.bat
```

### 2. 主服务器
**文件**: `Tcp.py`
- ✅ **基础功能**: 基本的TCP连接和数据接收
- ✅ **数据解析**: 支持GNSS数据解析
- ✅ **单设备**: 适合单设备测试

**启动方式**:
```bash
python Tcp.py
# 或使用批处理文件
start_server.bat
```

### 3. 延迟分析工具
**文件**: `数据包延迟分析工具.py`
- ✅ **延迟监控**: 实时监控数据包延迟
- ✅ **统计分析**: 提供详细的延迟统计报告
- ✅ **性能分析**: 帮助优化网络性能

**启动方式**:
```bash
python 数据包延迟分析工具.py
# 或使用批处理文件
启动延迟分析.bat
```

## 功能特性

### 数据格式支持
- ✅ **二进制格式**: 严格按照`gnss_data.h`结构体
- ✅ **TCP_FrameHeader**: 完整的帧头信息
- ✅ **GNSS_Data**: 完整的GNSS数据
- ✅ **Satellite_Info**: 详细的卫星信息数组

### 多设备管理
- ✅ **设备注册**: 自动注册新连接的设备
- ✅ **状态监控**: 实时监控设备在线状态
- ✅ **数据统计**: 每个设备的数据包统计
- ✅ **连接管理**: 自动处理连接和断开

### 性能优化
- ✅ **持久连接**: 支持TCP持久连接
- ✅ **并发处理**: 多线程处理多个客户端
- ✅ **延迟优化**: TCP_NODELAY减少延迟
- ✅ **内存管理**: 自动清理过期数据

## 安装和配置

### 环境要求
- Python 3.7+
- 网络连接
- 防火墙允许端口12345

### 安装依赖
```bash
pip install -r requirements.txt
```

### 配置服务器
默认配置:
- **监听地址**: 0.0.0.0
- **端口**: 12345
- **最大连接数**: 10

## 使用方法

### 1. 启动服务器
```bash
# 进入Tcp目录
cd Tcp

# 启动多设备服务器 (推荐)
python multi_device_server.py

# 或启动延迟分析工具
python 数据包延迟分析工具.py
```

### 2. 连接Android设备
1. 确保Android设备和服务器在同一网络
2. 在Android应用中配置服务器IP地址
3. 点击"开始持续上传"

### 3. 监控数据
服务器会实时显示:
- 设备连接状态
- 数据包接收情况
- GNSS数据解析结果
- 卫星信息详情

## 故障排除

### 常见问题

1. **连接失败**
   - 检查网络连接
   - 确认防火墙设置
   - 验证IP地址和端口

2. **数据解析错误**
   - 检查数据格式
   - 确认Android应用版本
   - 查看服务器日志

3. **延迟过高**
   - 使用延迟分析工具
   - 检查网络质量
   - 优化服务器配置

```bash
# 启用详细日志
python multi_device_server.py --debug
```
