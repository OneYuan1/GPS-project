# 云服务器部署指南

## 🎯 部署目标

将TCP服务器部署到云服务器，接收LocationUploader应用的数据并存储到数据库。

## 📋 部署架构

```
手机应用 (LocationUploader)
    ↓ TCP连接 (端口8280)
云服务器 (TCP服务器)
    ↓ 数据库连接
MySQL数据库 (端口3306)
```

## 🔧 部署步骤

### 1. 云服务器环境准备

#### 安装Python环境
```bash
# Ubuntu/Debian
sudo apt update
sudo apt install python3 python3-pip

# CentOS/RHEL
sudo yum install python3 python3-pip

# 验证安装
python3 --version
pip3 --version
```

#### 安装MySQL数据库
```bash
# Ubuntu/Debian
sudo apt install mysql-server

# CentOS/RHEL
sudo yum install mysql-server

# 启动MySQL服务
sudo systemctl start mysqld
sudo systemctl enable mysqld
```

### 2. 上传服务器代码

#### 上传文件到云服务器
```bash
# 使用scp上传
scp -r Tcp/ user@your-server-ip:/home/user/

# 或使用SFTP工具上传
```

#### 安装Python依赖
```bash
cd /home/user/Tcp
pip3 install -r requirements.txt
```

### 3. 配置服务器

#### 修改服务器配置
编辑 `Tcp.py` 文件，修改端口配置：

```python
class LocationServer:
    def __init__(self, host='0.0.0.0', port=8280):  # 修改端口为8280
        self.host = host
        self.port = port
```

#### 创建启动脚本
创建 `start_server.sh`：

```bash
#!/bin/bash
cd /home/user/Tcp
python3 Tcp.py
```

#### 设置权限
```bash
chmod +x start_server.sh
```

### 4. 配置防火墙

#### 开放必要端口
```bash
# Ubuntu/Debian (ufw)
sudo ufw allow 8280/tcp
sudo ufw allow 3306/tcp
sudo ufw enable

# CentOS/RHEL (firewalld)
sudo firewall-cmd --permanent --add-port=8280/tcp
sudo firewall-cmd --permanent --add-port=3306/tcp
sudo firewall-cmd --reload
```

### 5. 配置数据库

#### 创建数据库和用户
```sql
-- 连接MySQL
mysql -u root -p

-- 创建数据库
CREATE DATABASE location_data;

-- 创建用户
CREATE USER 'location_user'@'localhost' IDENTIFIED BY 'your_password';

-- 授权
GRANT ALL PRIVILEGES ON location_data.* TO 'location_user'@'localhost';
FLUSH PRIVILEGES;

-- 创建数据表
USE location_data;
CREATE TABLE location_packets (
    id INT AUTO_INCREMENT PRIMARY KEY,
    device_id VARCHAR(50),
    timestamp DATETIME,
    latitude DOUBLE,
    longitude DOUBLE,
    altitude DOUBLE,
    speed FLOAT,
    heading FLOAT,
    accuracy FLOAT,
    satellite_count INT,
    raw_data BLOB,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 6. 启动服务器

#### 直接启动
```bash
cd /home/user/Tcp
python3 Tcp.py
```

#### 后台运行
```bash
nohup python3 Tcp.py > server.log 2>&1 &
```

#### 使用systemd服务
创建 `/etc/systemd/system/location-server.service`：

```ini
[Unit]
Description=Location TCP Server
After=network.target

[Service]
Type=simple
User=your-user
WorkingDirectory=/home/user/Tcp
ExecStart=/usr/bin/python3 Tcp.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

启动服务：
```bash
sudo systemctl daemon-reload
sudo systemctl enable location-server
sudo systemctl start location-server
```

## 📱 手机应用配置

### TCP配置
```
传输方式: TCP
服务器地址: 您的云服务器公网IP
端口号: 8280
SSL加密: 关闭
```

### 配置步骤
1. 打开LocationUploader应用
2. 点击"远程网络配置"
3. 选择"TCP"传输方式
4. 输入云服务器公网IP
5. 输入端口8280
6. 保存配置

## ⚠️ 安全配置

### 防火墙配置
```bash
# 只允许必要端口
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow ssh
sudo ufw allow 8280/tcp
sudo ufw allow 3306/tcp
```

### 数据库安全
```sql
-- 限制数据库访问IP
REVOKE ALL PRIVILEGES ON location_data.* FROM 'location_user'@'%';
GRANT ALL PRIVILEGES ON location_data.* TO 'location_user'@'localhost';
```

### SSL/TLS配置
如果需要SSL加密，可以配置SSL证书：

```python
# 在Tcp.py中添加SSL支持
import ssl

context = ssl.create_default_context(ssl.Purpose.CLIENT_AUTH)
context.load_cert_chain(certfile="server.crt", keyfile="server.key")
```

## 🔧 故障排除

### 常见问题

1. **连接被拒绝**
   - 检查防火墙配置
   - 确认端口已开放
   - 检查服务器是否运行

2. **数据接收失败**
   - 检查服务器日志
   - 确认数据库连接
   - 验证数据格式

3. **性能问题**
   - 检查服务器资源
   - 优化数据库查询
   - 调整连接池配置

### 调试命令
```bash
# 检查服务状态
sudo systemctl status location-server

# 查看详细日志
journalctl -u location-server -f

# 检查端口占用
lsof -i :8280

# 测试数据库连接
mysql -u location_user -p -h localhost location_data
```
